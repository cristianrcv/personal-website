The Distributed Stream Library (DistroStreamLib) was developed as part of my PhD research at the Barcelona Supercomputing Center. It enables Hybrid Workflows that combine task-based workflows and dataflows in a single programming model, extending COMPSs to support continuous input and output data streams.

The library provides a homogeneous, generic, and simple representation of object and file streams in both Python and Java. It allows complex Data Science workflows to handle any data without dealing directly with the streaming back-end (e.g., Apache Kafka).

Source code available on [GitHub](https://github.com/bsc-wdc/distro-stream-lib).
