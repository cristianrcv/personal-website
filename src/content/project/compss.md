COMP Superscalar (COMPSs) is a programming framework developed at the Barcelona Supercomputing Center (BSC). It aims to facilitate the parallelization of existing applications written in Java, C/C++ and Python. Its main objective is to develop applications in a sequential way while the runtime system handles the inherent parallelism and abstracts the programmer from the underlying distributed infrastructure.

COMPSs provides scalability and elasticity features allowing the dynamic provision of resources in cloud environments. I contributed to COMPSs from 2014 to 2020 as a resident student, junior developer, and PhD student.

More details available at the [official COMPSs website](http://compss.bsc.es).
